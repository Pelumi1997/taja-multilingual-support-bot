# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-09-04

### Added

- FastAPI web demo and REST API.
- Optional constrained OpenAI Responses API RAG generation with deterministic fallback.
- English, Hausa, Igbo, Nigerian Pidgin and Yoruba language flow.
- Source-linked Taja FAQ knowledge base.
- Hybrid TF-IDF, fuzzy and keyword retrieval.
- Fintech safety classification, secret redaction and escalation metadata.
- Optional Redis sessions and Gupshup adapter.
- Docker, tests, CI, documentation and evaluation tooling.
