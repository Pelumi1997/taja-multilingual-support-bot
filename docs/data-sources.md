## Update policy

Website content should not be imported directly into production without review. To update the knowledge base:

1. record the page and review date;
2. compare the published wording with the current JSON entry;
3. obtain product/compliance approval for material changes;
4. update all five language versions;
5. run validation, tests and retrieval evaluation;
6. commit the change with a meaningful message.
